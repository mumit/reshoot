# A demo that stays current

Audience: maintainers who need a README or launch video after their UI changes.

Claim: run the same checked storyboard against an updated app to make a fresh
recording. The recording still needs owner review. No claim about novice setup,
time saved, automatic repair or unattended publication.

Story: show the UI change, run the actual CLI, play the updated task, compare the
two results, and end with reshoot and its repository address.

Deliverables: a roughly 22-second, silent 1080 by 1350 social MP4 with burned-in
text, and a roughly 11-second landscape README GIF. A companion MP4 preserves
the README loop without GIF compression. Generation waiting is omitted from the
social cut and explicitly labeled; the complete terminal recording is retained.
The app task plays at its original speed.

Only synthetic notes, headless browser pages and a clean VHS terminal are used.
Both versions share app code and the exact storyboard, selectors and assertions.
The difference is a heading, button label, and CSS. Never record the whole screen.
No existing media is replaced or published by this recipe.
