This is an assisted maintainer study in the existing Codex conversation. The agent
knows the prepared changes, performs the updates, and presents each fresh final;
the owner judges its MP4 and README GIF. It is not blind discovery or a novice
setup trial. Active human effort is unknown. Preparation and baseline review are
outside case timers. Case timing includes doctor checks, previews, failed attempts,
repairs, fresh final recording and exports, scans, explicit baseline comparison,
agent inspection, and owner response waiting. Cases run sequentially, with each
timer ending on its own explicit owner verdict.

Each case retains its task, beat IDs, captions, holds, and required assertions.
Necessary locator, URL, wait, tape, or edit repairs are allowed and recorded.
Failures, pending review, abandoned cases, or detector errors stay in the fixed
denominator. Completion requires a successful full fresh run, required checks and
scanning, explicit comparison, and owner acceptance of both final exports. Direct
editing of rendered footage is counted as manual video editing. The proposed
eight-of-ten target is evaluated only after every case has ended.
